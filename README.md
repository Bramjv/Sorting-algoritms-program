# Sorting-algoritms-program
This program sorts random arrays of random lengths (ranging from min_value to max_value), containing either integers or floating-point numbers in the range of 0 to 1000. The program implements the following sorting algorithms: quicksort, heapsort, radix sort, tim sort, merge sort, and bucket sort. After sorting the arrays, the measure_sort_time function calculates the sorting time and saves the results to a CSV file in the following order: "Algorithm", "Data Size", "Data Characteristic", "Time (s)". Additionally, using the matplotlib library, a chart is generated to visualize the sorting time relative to the number of elements in the array.
